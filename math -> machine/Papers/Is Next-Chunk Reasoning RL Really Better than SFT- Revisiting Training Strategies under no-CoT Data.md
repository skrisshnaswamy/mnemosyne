## The Core Idea

There is a lot of text in the world that is full of reasoning *content* but has no reasoning *trace*. A textbook derivation, an AoPS solution, a paper. It gives you the answer and a compressed sketch, not the messy step-by-step thinking a modern reasoning model is trained to produce. Call this **no-CoT data**. It is cheap and plentiful. Long chain-of-thought data — where a strong teacher model writes out the whole thought process and you keep only the runs that got the right answer — is expensive.

> [!NOTE] no-CoT data ^no-cot-data
> Text that contains real knowledge and solution patterns but no explicit chain of thought. Worked solutions, textbook derivations, research papers. Plentiful, but the "thinking" is missing.

A recent line of work (RPT, RLP, RMT, RLPT, PretrainZero) says: turn this into a reinforcement learning game. Show the model a prefix of the corpus, let it *think*, then let it guess the next token (or the next sentence). Reward it if the guess matches. The hope is that to guess well, the model must actually reason, so you get reasoning practice out of unlabelled text. Call this family **next-chunk reasoning** (NCR). These papers all report beating plain [[Distilling the Knowledge in a Neural Network|SFT]]-style supervised fine-tuning on the same data.

This paper's point is that they beat the *wrong* baseline. Every one of those papers compared against SFT on **no-CoT data alone**. But training only on no-CoT text destroys the model's long-CoT output format — it stops emitting `<think>` blocks and structured answers. So of course that baseline is bad. It is bad for a boring formatting reason, not a deep one.

The missing baseline is embarrassingly simple: **Mixed SFT** — throw the no-CoT data and the long-CoT data into one pile and do one ordinary supervised fine-tuning pass over the union. That is it. No rollouts, no reward model, no policy gradient.

Mixed SFT wins. After the same downstream RLVR stage (RL with verifiable rewards, i.e. GRPO on math problems with exact-match rewards), Mixed SFT averages **67.4** on six in-domain math benchmarks vs **64.2** for next-token reasoning and **63.6** for next-sentence reasoning — and it uses **over 60× less training compute**.

The second, more transferable finding: **pre-RLVR accuracy does not predict post-RLVR accuracy.** Mixed SFT is the *worst* checkpoint before RL — 27.5 average, about 20 points below everyone else — and the *best* after. If you had judged these strategies at the intermediate checkpoint, as everyone does, you would have picked the loser.

## The Methodology

**Base model.** Qwen3-30B-A3B-Base. Deliberately a *base* checkpoint, not an instruct one, so no prior post-training contaminates the comparison. This matters: several NCR papers start from an already-reasoning model, which hides how much of their gain is just the pre-existing long-CoT behaviour.

**Data.** Everything crawled from AoPS (Art of Problem Solving).
- **long-CoT**: 152K trajectories, ~1.95B tokens. Generated by DeepSeek-V3.2, max 64K generation length, keep only trajectories whose final answer is correct (rejection sampling).
- **no-CoT**: 421K short original AoPS solutions, ~0.53B tokens. Derivations, no explicit thinking.
- **RLVR set**: DAPO-Math-17K.
- All three deduplicated against the eval benchmarks.

**The five strategies compared**, all from the same base, all followed by the identical RLVR stage:

1. **Reasoning SFT** — long-CoT only. The control.
2. **Sequential SFT** — no-CoT first, then long-CoT, to restore the format.
3. **Mixed SFT** — both at once, one stage, one epoch.
4. **Reasoning SFT + NTR** (next-token reasoning, RPT-style).
5. **Reasoning SFT + NSR** (next-sentence reasoning, RLPT-style).

They explicitly *excluded* "Reasoning SFT then no-CoT SFT" because it produces format-incoherent garbage.

**The SFT loss** is just token-level negative log-likelihood — plain [[Cross Entropy|cross entropy]] over the response:

$$\mathcal{L}_{\text{SFT}}(\theta)=-\mathbb{E}_{(x,y)\sim\mathcal{D}}\left[\frac{1}{|y|}\sum_{t=1}^{|y|}\log\pi_\theta(y_t\mid x,y_{<t})\right]$$

The three SFT variants differ **only** in what $\mathcal{D}$ is. Reasoning SFT: long-CoT. Sequential: two runs, one per source. Mixed: the union.

**NTR objective.** First, run Qwen3-30B-A3B over the whole no-CoT corpus and record the per-token next-token entropy. Keep only the **top 20% highest-entropy tokens** as prediction targets — the assumption being that low-entropy tokens are trivially predictable and teach nothing. For a prefix $x_{<t}$, sample $G$ rollouts $o^i = (c^i, y^i)$ where $c^i$ is the thinking trace and $y^i$ the predicted continuation. Reward is byte-level prefix matching:

$$r^i=\begin{cases}1,&\bar{y}^i=\bar{x}_{\geq t}[1{:}l]\ \text{and}\ l\in\mathcal{L}_{\text{gt}}\\ 0,&\text{otherwise}\end{cases}$$

where $\bar{\cdot}$ is the byte sequence, $l = |\bar{y}^i|$, and $\mathcal{L}_{\text{gt}}$ is the set of cumulative byte lengths of the ground-truth tokens. So the guess counts as correct if its bytes are a valid token-boundary-aligned prefix of the truth. Maximise $\mathbb{E}[r^i]$ with [[Proximal Policy Optimization Algorithms|GRPO]].

**NSR objective.** Segment each no-CoT example into sentences. Given preceding context $s_{<i}$, generate a thought $c$ and a predicted sentence $\hat{s}_i$. Reward is a binary judgement from a generative reward model — gpt-oss-120b with `reasoning_effort=high` — on whether $\hat{s}_i$ is semantically consistent with $s_i$. No entropy filtering here; every sentence is a target.

**Hyperparameters that mattered.**

| | NTR | NSR | RLVR |
|---|---|---|---|
| Global batch | 4096 | 256 | 256 |
| Rollouts/prompt | 64 | 16 | 16 |
| Max response | 2K | 32K | 32K |
| LR | 1e-6 | 1e-6 | 1e-6 |
| KL penalty | off | off | off |

All RL on 64 H200s. SFT is one epoch, max sequence length 131,072. Eval decoding: temperature 0.8, top-p 0.999, top-k 0, 64K max tokens. Answer parsed from `\boxed{}` or the span after `</think>`.

## Ablation Studies and Experiments

**Headline table** (avg@32 on AIME/HMMT/IMO, avg@4 on GPQA-D, pass@1 on HLE/MMLU-Pro):

| Method | AIME24 | AIME25 | HMMT25 | IMO-Ans | HLE | GPQA-D | MMLU-Pro |
|---|---|---|---|---|---|---|---|
| Reasoning SFT | 73.33 | 64.17 | 34.16 | 34.50 | 6.91 | 46.21 | 74.89 |
| + RLVR | 81.98 | 76.67 | 43.33 | 47.25 | 7.22 | 56.94 | 73.95 |
| Sequential SFT | 71.25 | 62.81 | 34.17 | 35.75 | 6.52 | 46.21 | 68.82 |
| + RLVR | 74.90 | 69.27 | 32.92 | 41.25 | 6.79 | 54.55 | 71.10 |
| **Mixed SFT** | 45.52 | 42.50 | 10.42 | 12.50 | 6.71 | 36.24 | 56.61 |
| **+ RLVR** | **87.50** | **85.73** | **55.00** | **54.00** | **9.24** | **60.98** | **75.84** |
| Reasoning SFT + NTR | 74.69 | 67.29 | 36.77 | 38.00 | 7.59 | 53.66 | 73.46 |
| + RLVR | 87.50 | 84.38 | 50.42 | 46.50 | 7.68 | 57.70 | 74.03 |
| Reasoning SFT + NSR | 74.27 | 63.54 | 38.33 | 36.00 | 7.46 | 42.93 | 70.31 |
| + RLVR | 85.52 | 80.92 | 48.85 | 48.25 | 7.72 | 56.31 | 74.89 |

Look at the Mixed SFT row before RLVR. It is a disaster. Then look at it after. Average over all nine benchmarks: pre-RLVR **27.5** → post-RLVR **61.1**, a jump of **33.7 points**. Every other method starts between 45.9 and 48.8 and gains only 3.3 to 10.3. Sequential SFT + RLVR actually goes *down* on HMMT25 (34.17 → 32.92).

**Cost.** NTR and NSR each burn >60× the GPU hours of SFT on the same no-CoT corpus, measured at step 160 where both peak pre-RLVR. NSR is worse still because it needs a 120B generative judge in the loop.

Now the four analyses, which are the real content.

**Observation 1 — the entropy filter is not selecting reasoning-hard tokens.** NTR's whole premise is that high-entropy tokens are the hard, reasoning-demanding ones. They sampled 2,048 tokens from the top-20% high-entropy pool and, across NTR checkpoints, measured three things: entropy at those positions, accuracy *with* a reasoning step, and accuracy with *direct* prediction.

- Reasoning accuracy climbs 0.29 → 0.55.
- Entropy at the same tokens stays **flat**.
- **No-reasoning accuracy stays around 0.48 the whole time.**

That last number kills it. Nearly half of the supposedly hard targets are already predicted correctly with no thinking at all. High token entropy measures local uncertainty of the raw corpus, not reasoning difficulty.

> [!NOTE] Entropy ≠ difficulty ^entropy-not-difficulty
> A token can be high-entropy because the corpus is locally ambiguous (many plausible phrasings), not because predicting it requires inference. Filtering on entropy to find "hard" supervision targets is a heuristic that does not survive measurement.

**Observation 2 — the traces collapse into local completion.** Since half the targets are locally predictable, the model can farm the reward without reasoning. Over NTR training, generation entropy falls and response length falls. Inspecting the traces: the model converges on a handful of repetitive templates across wildly different prefixes. It does a short, template-like completion of the immediate context. NSR does the same thing one level up — the "predicted sentence" is usually a direct continuation of the preceding text. The reconstruction reward is satisfied by pattern-matching, not reasoning, so there is no reasoning structure left for RLVR to amplify.

**Observation 3 — fixing the collapse does not help. (The best ablation in the paper.)** The obvious rescue: the ceiling is low *because* of entropy collapse, so preserve exploration. They added two interventions.

*Stochastic filtering of easy groups.* For a rollout group with in-group success rate $\rho = n_+/n$, keep it with probability
$$p_{\text{keep}}(\rho)=\begin{cases}1,&\rho\leq 0.25\\ 1-\tfrac{6}{5}(\rho-0.25),&0.25<\rho\leq 1\end{cases}$$
so easy prompts get dropped smoothly (down to 0.1 at $\rho = 1$) instead of at a hard threshold.

*Adaptive down-weighting of positive advantages.* With $\bar{H}$ the batch-mean per-token policy entropy,
$$\widetilde{A}_{i,t}=\begin{cases}0.75\cdot A_{i,t},&\bar{H}<0.5 \text{ and } A_{i,t}>0\\ A_{i,t},&\text{otherwise}\end{cases}$$
Only positive advantages shrink when the policy gets over-confident, so negative ones get relatively more pull and the policy stops funnelling into one template.

The interventions **worked as engineering**: entropy held near 0.52, response length near 640 tokens for the whole run. And post-RLVR accuracy went **down** on all nine benchmarks (AIME24 87.50 → 86.42, IMO-Ans 46.50 → 44.75, GPQA-D 57.70 → 56.81).

So entropy collapse is not the disease. Vanilla NTR reaches its ceiling *by* converging onto the peaked template policy. Blocking that convergence removes a working solution without providing a better one.

**Observation 4 — ruling out the token-coverage confound.** Fair objection: NCR is 60× more expensive, so it sees far fewer tokens of the corpus. Maybe SFT wins purely on exposure. Test: start NCR from the **Mixed SFT** checkpoint, which has already digested the whole no-CoT corpus, then run the same RLVR.

| | AIME24 | AIME25 | HMMT25 | HMMT26 |
|---|---|---|---|---|
| Mixed SFT + RLVR | 87.50 | 85.73 | 55.00 | 51.52 |
| Mixed SFT + NTR + RLVR | 86.35 | 84.58 | 53.73 | 50.50 |
| Mixed SFT + NSR + RLVR | 87.21 | 84.67 | 53.15 | 49.52 |

Nothing. Slightly worse across the board. Once SFT has absorbed the data, neither NCR objective adds anything RLVR can use.

**Observation 5 — why Mixed SFT's pre-RLVR score is so bad.** It is a *format* problem, not a knowledge problem. Long-CoT data has `<think>...</think>` markers and a standard answer format; no-CoT data has neither. Training on both at once gives the model conflicting structural conventions. Two failure modes appear: responses with **multiple disjoint `<think>` segments**, and **no-think direct answers** where the block is skipped entirely and the model jumps to the answer. Both wreck solution quality without touching the underlying maths. During RLVR the format-compliance rate rises fast and accuracy rises alongside it — the verifier reward re-imposes a consistent format, and the knowledge underneath is then expressible.

**Observation 6 — why Sequential SFT loses.** Sequential's second stage (long-CoT) partially overwrites what its first stage (no-CoT) learned. Classic catastrophic forgetting across stages. Probe: 100 problems sampled from the *no-CoT training corpus* — both pipelines saw them. Evaluate after RLVR, so format is equalised, 8 samples each.

| | No-CoT Probe (avg@8) |
|---|---|
| Sequential SFT + RLVR | 59.19 |
| Mixed SFT + RLVR | 68.63 |

RLVR does not recover knowledge that was erased before it started.

**Where the advantage shrinks.** At pass@$n$ instead of avg@$n$, post-RLVR scores saturate (several methods hit 93.33 on AIME24/25) and the gap compresses. Mixed SFT still ties or leads on eight of nine, with AIME26 going to NTR/NSR. Their argument for avg@$n$ as the primary metric: pass@$n$ measures the best of $n$ samples and cannot distinguish mature strategies whose lucky samples agree; avg@$n$ measures expected per-sample quality, which is what you actually deploy.

## Worth Remembering

- **The methodological lesson generalises far past this paper.** If a training stage is an *initialisation* for a later stage, evaluating it at its own checkpoint is not just noisy — it can be systematically inverted. Mixed SFT was 20 points behind and ended 13 points ahead. Any paper comparing pre-training or mid-training recipes on intermediate evals is at risk of this.
- **Check what your baseline is broken by.** The NCR papers' baseline was weak because no-CoT-only SFT destroys output format, a shallow and fixable problem. The fix was mixing in data they already had. Related in spirit to [[RoBERTa- A Robustly Optimized BERT Pretraining Approach|RoBERTa]]'s undertrained-baseline finding and [[Are We Really Making Much Progress- A Worrying Analysis (RecSys, best paper)|the RecSys reproducibility paper]] — a large fraction of "new method wins" is "old method was run badly."
- **The entropy-controlled NTR result is the one to internalise.** A collapse you can see in your training curves is not automatically the cause of your bad final number. They fixed the visible symptom cleanly and got worse results. Diagnosing from training dynamics alone is dangerous.
- **Limitations the authors admit.** One fixed mixing ratio between no-CoT and long-CoT, never swept — so the recipe is "mix them" with no guidance on proportions, including the scarce-source regime. And everything, corpus and benchmarks alike, is mathematics. Whether this holds for code, multilingual, or general scientific text is untested.
- **Practical caveat on scale.** This is one 30B MoE base model, one data source (AoPS), one RLVR set. The 60× compute claim is measured at NTR/NSR step 160, their pre-RLVR peak — a shorter NCR run would narrow the gap but also lower the ceiling.
- **Open question.** Is Mixed SFT's advantage really about *retention*, or is the format instability itself doing something useful — knocking the model off a rigid format attractor so RLVR explores more? The paper treats the instability purely as a cost that RLVR pays off. The 33.7-point jump is large enough that "it just recovers" feels like an incomplete explanation.
- **Related work worth noting:** DeepSeek-R1's second SFT stage, Qwen3's Thinking Mode Fusion, and LS-Mixture all mix CoT and non-CoT in one SFT stage — but all place that mixture *after* reasoning RL, as recovery. This paper is the first to test it as the *initialisation* for RL.
